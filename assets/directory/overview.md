# Link checker

Check every link on the page open in the editor, before visitors find the broken ones.

- **Link checker** sidebar:
  - opens each internal link on the site the way a visitor would, and checks external links;
  - flags links to content that was deleted or isn't published - the site hides those links
    without any error, so they are easy to miss;
  - flags references to blocks or images that no longer exist, and links that go through a redirect.

It reads the page, its inline blocks and the shared blocks it uses, including links inside rich text and HTML.
